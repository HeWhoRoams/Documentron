# Documentron AppDoc VS Code Extension

Commands:
- AppDoc: Run All — runs inspect → convert → synthesize → verify → report
- AppDoc: Run Selected Steps — pick a subset of steps

Both commands execute the Python orchestrator at `Documentron/ux/cli/appdoc.py` in the workspace root.

Usage:
- Open your repo (containing the `Documentron/` folder) in VS Code
- Open Command Palette → run one of the commands above
